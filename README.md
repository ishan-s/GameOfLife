# Conway's Game of Life

A browser-based implementation of John Conway's "Game of Life," a cellular automaton that evolves based on a set of simple mathematical rules.

## Overview

This project provides an interactive grid where users can simulate the Game of Life directly in their web browser. It is built using clean, modular JavaScript and standard web technologies.

## Features

* **Interactive Grid:** Click cells to toggle their state between alive and dead.
* **Control System:** Start, stop, and clear the simulation at any time.
* **Pattern Library:** Includes support for predefined shapes (`golshapes.js`) to quickly seed the grid with common configurations like gliders, oscillators, and spaceships.
* **Stats Tracking:** Real-time statistics on the current generation and population count.

## Technologies Used

* **HTML5:** Structuring the game interface and canvas.
* **CSS3:** Styling and layout for a responsive grid.
* **JavaScript:** Logic for the game engine and simulation rules.

## Getting Started

### Prerequisites

You only need a modern web browser (Chrome, Firefox, Safari, or Edge) to run this project.

### Running the Project

1. Clone this repository to your local machine:
```bash

git clone https://github.com/ishan-s/GameOfLife.git

```
2. Open the `index.html` file in your preferred web browser.
3. Use the control buttons to start the simulation and interact with the grid.

## Project Structure
* `index.html`: The main entry point.
* `golmain.js`: Core game logic and loop control.
* `golshapes.js`: Definitions for various pre-built patterns.
* `golstats.js`: Handling the display of simulation statistics.
* `golstyle.css`: Styling for the interface.
